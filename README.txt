NEON//FORM — Typographic Portrait Studio

Included files:
- index.html: full studio interface
- style.css: responsive cyberpunk art direction
- script.js: image processing, 3 art modes, animation, PNG export and WebM export

Art modes:
1. Neon cyberpunk — cyan, violet and magenta gradients, restrained scan effects and digital rain.
2. True photo colour — uses sampled RGB colours from the source photograph.
3. Gallery editorial — muted, refined tones for an art-print appearance.

To run locally, keep the three web files in the same folder and open index.html in a recent browser.
To publish on GitHub Pages, upload all three files to the repository root (or the same subfolder).
Google Fonts are loaded online for the intended display typography; system fallbacks are included.
The photo is processed locally in the browser. Video export is WebM and requires MediaRecorder support.
